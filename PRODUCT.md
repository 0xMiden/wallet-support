# Bread Wallet support

## Register

product

## Users

Bread Wallet users on mobile and browser extension who need an answer while setting up, recovering access, moving assets, or checking a transaction. They may be worried about wallet access or funds and need clear instructions with minimal distraction.

## Product Purpose

Help users reach a verified answer quickly through search, task-based topics, readable guides, related help, and the approved feedback form. Consumer help stays separate from developer integration documentation.

## Brand Personality

Warm, clear, reassuring. The reference is the current Bread Wallet implementation, particularly its crisp, left-aligned design system, rather than a generic support template. Brian explicitly requested alignment with the wallet's colors and fonts on 2026-10-14.

## Anti-references

Oversized pastel artwork cards, all-uppercase topic titles, heavily rounded display type throughout long articles, decorative dashboard metrics, marketing illustrations that imply unreleased wallet features, or competing search fields.

## Design Principles

- Put the user's next task first: search, a common question, or a topic.
- Use the wallet's visual vocabulary so moving into help feels continuous.
- Make long answers easy to scan and read.
- Use public, verified behavior; explain release and network availability clearly.
- Let interactions serve navigation and comprehension.

## Accessibility & Inclusion

WCAG AA text contrast, visible keyboard focus, accessible navigation drawers and platform tabs, comfortable reading measure, 200% zoom, reduced motion, and responsive layouts from 320px upward.
